# 1C-CRM-System
Учебная база 1С для первого итогового проекта на платформе Skillbox.
## Что реализовано в проекте:
- Подсистема CRM с командным интерфейсом
- Справочник статусов контрагентов (с статусом по умолчанию "Потенциальный клиент")
- Документ "Взаимодействие" и перечисление "Виды взаимодействий"
- Регистр сведений "Напоминания"
- Регистр сведений "Документы по контрагентам"
- Система скидок в документе "Заказ покупателя"
- Отчет "Продажи по покупателям" (СКД)
- Печатная форма "Счёт на оплату"
## Как развернуть базу:
1. Скачайте файл `Проектная работа курса «Основы конфигурирования в 1С и оперативный учёт»1Cv8.dt` из этого репозитория.
2. Откройте 1С:Предприятие и создайте новую пустую информационную базу.
3. Запустите её в режиме **Конфигуратор**.
4. В меню выберите: **Администрирование** -> **Загрузить информационную базу...**
5. Укажите путь к скачанному файлу `.dt` и дождитесь окончания загрузки.
6. Запустите базу в режиме 1С:Предприятие
